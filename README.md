# 👤 Kullanici Kayit Otomasyonu

Gelen musterilerin bilgilerini otomatik olarak veritabanina kaydeden kayit yonetim sistemi.

## 📋 Proje Hakkinda

Bu sistem, isletmelerin musteri bilgilerini (ad, soyad, iletisim bilgileri vb.) duzenli sekilde veritabanina kayit etmesini saglar.

## 🛠️ Kullanilan Teknolojiler

- **Python** — Ana programlama dili
- **SQL** — Veritabani yonetimi

## 🚀 Nasil Calistirilir

```bash
git clone https://github.com/MucoX339/kullan-c-kay-totomasyonu.git
cd kullan-c-kay-totomasyonu
python main.py
```
